# Интернет-магазин


## Описание проекта
Skystore  — вариант хранения ваших плагинов и примеров кода, который вы бы хотели продать


## Структура проекта

- **Корневая директория**: содержит файлы настройки проекта, `manage.py` и др.
- **Приложение `catalog`**: отвечает за каталог товаров и основные страницы (главная, контакты).
- **Шаблоны (`templates/`)**: HTML‑шаблоны с использованием Bootstrap.
- **Статические файлы (`static/`)**: CSS, JS, изображения.
